# 2026-09-05 CONV 继续优化实验记录

本轮在鲲鹏节点单 NUMA 5、38 线程、BiSheng、未修改 `bench_conv.c` 条件下进行。每个候选均上传到独立远端目录，四个公开 Case 全部通过 `1e-5` 校验。

正式保留的改动是 packed kernel 分片阈值从 256 KiB 调整到 128 KiB，提交为 `580334d`。该配置来自此前多轮实验，较 256 KiB 版本更稳定。

汇编完整组候选和额外合法尾宽尺寸均 PASS，但没有可重复的性能收益，因此没有合入正式路径。列优先、简单尾部展开和其他预取参数沿用历史实验结论，不再作为默认配置。

后续若继续冲击 59k–60k，应改变工作单元：优先研究相邻 64 列 tile 的输入窗口共享/软件流水，或减少 `kernelHeight + 15` 物理行 halo 的新 ZA/Toeplitz 数据流。普通调度、复制数和预取微调不足以填补剩余差距。
